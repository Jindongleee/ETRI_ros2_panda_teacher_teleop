# 1. 시스템 아키텍처 및 제어 이론

## 1.1 프로젝트 개요

본 프로젝트는 **세 가지 입력 장치**(Joystick, Vive Tracker, OmyL100 리더 암)를 사용하여 **Franka Emika Panda** 로봇의 **텔레오퍼레이션(Teleoperation)**을 구현하고, **모방학습(Imitation Learning)**을 위한 State-Action 데이터를 수집하는 시스템이다.

### 핵심 목표

- 입력 장치별 텔레오퍼레이션 파이프라인 구축
- RViz 기반 시뮬레이션 환경에서의 실시간 조작
- 15~20Hz 샘플링 레이트의 데이터 수집 파이프라인 구축

## 1.3 제어 이론 및 공학적 기법

### 1.3.1 좌표 공간 (Coordinate Spaces)

| 좌표 공간 | 설명 | 사용 위치 |
|-----------|------|-----------|
| **Joint Space** | 각 조인트의 각도 \(\theta_i\) | `/leader/joint_states`, `/joint_states` |
| **Cartesian Space (Task Space)** | 엔드이펙터의 위치와 자세 \((x, y, z, q_x, q_y, q_z, q_w)\) | TF 변환, EE 포즈 |
| **Velocity Space** | 선속도 + 각속도 \((v_x, v_y, v_z, \omega_x, \omega_y, \omega_z)\) | `/servo_node/delta_twist_cmds` |

### 1.3.2 Forward Kinematics (FK) — OmyL100

OmyL100 리더 암의 조인트 각도에서 엔드이펙터 포즈를 계산한다.

**구현 방법**: TF2 라이브러리의 `lookup_transform()` 사용

```
Joint States (θ₁...θ₆) → robot_state_publisher (URDF 기반 FK) → TF tree
→ tf_buffer.lookup_transform('leader_link0', 'leader_link7') → EE Pose
```

**수학적 표현**:

각 링크의 변환 행렬 \(T_i\)를 순차적으로 곱하여 엔드이펙터 포즈를 계산한다:

\[
T_{0}^{7} = T_{0}^{1}(\theta_1) \cdot T_{1}^{2}(\theta_2) \cdot \ldots \cdot T_{6}^{7}(\theta_6)
\]

실제로는 ROS2의 `robot_state_publisher`가 URDF의 DH 파라미터를 기반으로 자동 계산하며, 결과를 TF 트리로 브로드캐스트한다.

### 1.3.3 Inverse Kinematics (IK) — MoveIt Servo (KDL)

TwistStamped 속도 명령을 Joint Trajectory로 변환한다.

**IK 솔버**: KDL (Kinematics and Dynamics Library)

```yaml
# kinematics.yaml
panda_arm:
  kinematics_solver: kdl_kinematics_plugin/KDLKinematicsPlugin
  kinematics_solver_search_resolution: 0.005
  kinematics_solver_timeout: 0.05
```

**Jacobian 기반 속도 IK**:

MoveIt Servo는 내부적으로 Jacobian 행렬을 사용하여 Cartesian 속도를 Joint 속도로 변환한다:

\[
\dot{q} = J^{-1}(\theta) \cdot \dot{x}
\]

여기서:
- \(\dot{q}\) : 조인트 각속도 벡터 (7×1, Panda는 7-DOF)
- \(J(\theta)\) : Jacobian 행렬 (6×7)
- \(\dot{x}\) : Cartesian 속도 벡터 (6×1: \([v_x, v_y, v_z, \omega_x, \omega_y, \omega_z]\))

7-DOF 로봇이므로 Jacobian이 정방행렬이 아니며, **Pseudo-inverse**를 사용한다:

\[
\dot{q} = J^{\dagger} \cdot \dot{x} = J^T(JJ^T)^{-1} \cdot \dot{x}
\]

**특이점(Singularity) 처리**:

```yaml
# servo_config.yaml
lower_singularity_threshold: 10.0
hard_stop_singularity_threshold: 20.0
```

Jacobian의 조건수(condition number)를 모니터링하여, 특이점 근처에서 속도를 자동으로 감속하거나 정지시킨다.

### 1.3.4 Quaternion 연산

OmyL100과 Vive 모두 **방향(Orientation)** 변화에서 각속도를 계산할 때 Quaternion 연산을 사용한다.

**상대 회전 계산**:

\[
q_{rel} = q_{curr} \cdot q_{prev}^{-1}
\]

**Quaternion 역원**:

\[
q^{-1} = [w, -x, -y, -z] \quad (\text{단위 쿼터니언의 경우})
\]

**Quaternion → Axis-Angle 변환**:

\[
\theta = 2 \cdot \arccos(w), \quad \hat{n} = \frac{[x, y, z]}{\sin(\theta/2)}
\]

**각속도 계산**:

\[
\omega = \frac{\theta \cdot \hat{n}}{\Delta t}
\]

Vive에서는 이와 다른 **Quaternion 미분 기반 근사**를 사용한다:

\[
\omega_x = \frac{2(-q_w \cdot \Delta q_x + q_x \cdot \Delta q_w + q_z \cdot \Delta q_y - q_y \cdot \Delta q_z)}{\Delta t}
\]

### 1.3.5 좌표계 변환 (Coordinate Frame Transformation)

#### SteamVR → ROS2 좌표 변환 (Vive)

SteamVR은 Y-up 좌표계, ROS2는 Z-up 좌표계를 사용한다:

| SteamVR 축 | ROS2 축 | 변환 |
|-----------|---------|------|
| X (오른쪽) | -Y | 반전 |
| Y (위) | Z | 직접 매핑 |
| Z (뒤) | -X | 반전 |

```cpp
// vive_node.cpp
transform.translation.x = -vrData.pose_z;   // VR Z → ROS -X
transform.translation.y = -vrData.pose_x;   // VR X → ROS -Y
transform.translation.z = vrData.pose_y;    // VR Y → ROS Z
```

#### Leader-Follower 오프셋 (OmyL100)

클러치 활성화 시 Leader/Follower 간 오프셋을 계산하여 상대 좌표계로 제어한다:

\[
\Delta P_{offset} = P_{follower} - P_{leader}
\]

\[
q_{offset} = q_{follower} \cdot q_{leader}^{-1}
\]

### 1.3.6 중력 보상 (Gravity Compensation) — OmyL100

OmyL100 리더 암은 **Current Control 모드**(전류 제어)로 동작하며, 중력 보상 컨트롤러가 적용된다.

**알고리즘**: KDL (Kinematics and Dynamics Library)을 사용한 역동역학(Inverse Dynamics) 기반 중력 토크 계산

```yaml
# hardware_controller_manager.yaml (leader)
gravity_compensation_controller:
  joints: [joint1, joint2, joint3, joint4, joint5, joint6]
  command_interfaces: [effort]
  friction_coefficients: [0.8, 0.8, 0.8, 0.1, 0.1, 0.1]
  torque_scaling: [1.0, 1.0, 1.0, 0.8, 0.8, 1.0]
```

**중력 토크 계산**:

\[
\tau_{gravity} = G(\theta) = \sum_{i=1}^{n} J_i^T(\theta) \cdot m_i \cdot g
\]

**마찰 보상**: 각 조인트에 마찰 계수를 적용하여 정마찰력을 보상한다.

### 1.3.7 스프링 액추에이터 컨트롤러 — OmyL100 그리퍼

`rh_r1_joint` (그리퍼)에는 스프링 효과를 시뮬레이션하는 effort 기반 컨트롤러가 적용된다.

```yaml
spring_actuator_controller:
  joints: [rh_r1_joint]
  command_interfaces: [effort]
```

### 1.3.8 Butterworth Low-Pass Filter — MoveIt Servo

MoveIt Servo의 출력에 Butterworth 필터가 적용되어 급격한 속도 변화를 완화한다:

```yaml
smoothing_filter_plugin_name: "online_signal_smoothing::ButterworthFilterPlugin"
low_pass_filter_coeff: 1.1
```

### 1.3.9 포즈 필터링 — Vive Tracker

Vive 포즈 데이터에 Low-pass 필터가 적용된다:

- **위치**: `filtered = α × current + (1-α) × previous` (α = 0.9999)
- **방향**: SLERP (Spherical Linear Interpolation)

### 1.3.10 속도 정규화 (Velocity Normalization)

모든 입력 모드에서 MoveIt Servo에 보내는 속도 명령은 `[-1.0, 1.0]` 범위로 정규화된다:

```python
max_component = max(|vx|, |vy|, |vz|, |ωx|, |ωy|, |ωz|)
if max_component > 1.0:
    scale = 1.0 / max_component
    twist *= scale
```

## 1.4 입력 장치별 제어 파이프라인 상세

### 1.4.1 Joystick → Panda

```
Joystick USB → joy_node → /joy (Joy) → joy_to_twist_node
                                         │
                                         ├─ 축 매핑 (Left Stick → X/Y, Right Stick → Roll/Pitch)
                                         ├─ 버튼 매핑 (L1/L2 → Z, R1/R2 → Yaw)
                                         ├─ Deadzone 적용 (10%)
                                         ├─ 스케일링 (linear: 3.0, angular: 3.5)
                                         └─ 정규화 (max > 1.0이면 스케일 다운)
                                         │
                                         ▼
                               /servo_node/delta_twist_cmds
                                         │
                               ┌─────────▼─────────┐
                               │ MoveIt Servo (IK)  │
                               │ Jacobian⁺ × twist  │
                               └─────────┬─────────┘
                                         ▼
                            /panda_arm_controller/joint_trajectory
```

**제어 방식**: **Rate Control** (속도 제어)
- 스틱을 기울인 만큼 해당 방향으로 속도 발생
- 스틱을 놓으면 정지 (Zero Velocity)
- 6-DOF 제어: XYZ 위치 + Roll/Pitch/Yaw 자세

### 1.4.2 Vive Tracker → Panda

```
SteamVR/OpenVR → vive_input (TCP:12345) → vive_node (ROS2)
                                            │
                                ┌───────────▼───────────┐
                                │  Y-up → Z-up 좌표 변환  │
                                │  Low-pass 필터링         │
                                │  상대 포즈 계산           │
                                └───────────┬───────────┘
                                            ▼
                             /vive/controller/pose (PoseStamped)
                                            │
                              ┌─────────────▼─────────────┐
                              │    vive_to_twist_node      │
                              │    ΔPose / Δt → Velocity   │
                              │    좌표계 재매핑             │
                              │    Quaternion 미분 → ω      │
                              └─────────────┬─────────────┘
                                            ▼
                                  /servo_node/delta_twist_cmds
```

**제어 방식**: **Position-Velocity Mapping** (위치 미분 기반 속도 제어)
- 컨트롤러의 위치 변화량을 시간으로 나누어 속도 계산
- 트리거 버튼으로 초기 기준점(Origin) 설정
- 6-DOF 제어: 위치 + 자세 동시 추적

### 1.4.3 OmyL100 → Panda

```
Dynamixel 모터(ID 1~7) → dynamixel_hardware_interface
         │                  (4Mbps, Current Control Mode)
         ▼
  ros2_control_node (200Hz)
         │
         ├─ gravity_compensation_controller (중력 보상)
         ├─ spring_actuator_controller (그리퍼 스프링)
         └─ joint_trajectory_command_broadcaster
         │
         ▼
  /leader/joint_states (JointState)
         │
    ┌────┴─────────────────────────────────┐
    ▼                                       ▼
omy_l100_to_twist_node                omy_l100_to_gripper_node
    │                                       │
    ├─ TF lookup (FK)                      ├─ rh_r1_joint 읽기
    │  leader_link0 → leader_link7         ├─ [-1.0, 1.0] → [0.0, 0.8]
    ├─ ΔPose / Δt → Velocity              │  선형 매핑
    ├─ Quaternion → Axis-Angle → ω        │
    ├─ 스케일링 (lin: 5.0, ang: 5.0)      └─► /gripper/position
    ├─ 축 반전 (Y: -1, AngX: -1, AngY: -1)
    └─ 속도 제한 (lin: 20m/s, ang: 20rad/s)
    │
    ▼
/servo_node/delta_twist_cmds
```

**제어 방식**: **Leader-Follower Teleoperation** (FK → 속도 → IK)
- **Leader**: OmyL100 (Current Control + 중력 보상 → 자유 조작 가능)
- **Follower**: Panda (MoveIt Servo → IK → Joint Trajectory)
- OmyL100의 FK 결과로부터 속도를 계산하고, Panda의 IK로 변환

**핵심 수학적 흐름**:

\[
\theta_{leader} \xrightarrow{FK} P_{ee,leader} \xrightarrow{\frac{\Delta P}{\Delta t}} \dot{x} \xrightarrow{J^{\dagger}} \dot{\theta}_{follower}
\]

### TF 프레임 트리

```
world
  └─ panda_link0
       ├─ panda_link1 ~ panda_link8
       │    └─ gripper_tip_link (Robotiq)
       │         ├─ finger_joint
       │         └─ (기타 그리퍼 관절)
       └─ leader_link0 (OmyL100, namespace: leader_)
            └─ leader_link1 ~ leader_link7
```
